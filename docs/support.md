# Mac-imbox 使用帮助 / Support

[中文使用指南](../README.md) · [English guide](../README.en.md)

**未读数消失了？** 先看原应用是否在运行、Dock 或菜单栏是否显示数字。更新后若面板提示权限不足，在「系统设置 → 隐私与安全性 → 辅助功能」（部分版本称「设备控制和数据访问」）重新添加并启用应用程序目录里的消息板。

**Missing unread counts?** Check that the original app is running and exposes a numeric badge. If the panel reports missing permission after an update, add the installed copy of Mac-imbox again in System Settings → Privacy & Security → Accessibility.

**联系开发者 xschao / Contact the developer** · [提交问题 / Open an issue](https://github.com/uniquechao/Mac-imbox/issues/new)

请提供 macOS 版本、消息板版本和操作步骤。GitHub 问题是公开的，上传截图前请遮盖联系人、消息及其他私人信息。

Include your macOS version, Mac-imbox version and steps to reproduce. Issues are public. Redact names, messages and other personal information before uploading screenshots.
